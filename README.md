# Pörssisähkö-widget
KDE Plasma widget that shows the current electricity spot price in Finland.

Also check out the [new Android app](https://github.com/vil/spot) for viewing the electricity price!

### Installation
1. `git clone https://github.com/vil/spot-widget.git`
2. `cd spot-widget`
3. `chmod +x setup.sh`
4. `./setup.sh`
5. Enter edit mode and press add widgets.
6. Search "Pörssisähkö" and add it to your panel.

Or instead you can install it using the widget manager on KDE by searching for it.
